# AirGestureControl
A tool that lets you scroll by gesturing in front of your phone - **WIP!!**

Have you ever seen a Huawei phone with that fancy function? Basically that thing but trying to be more universal

This project is vibe coded and is not recommended to compile and run on your device, for it is made for Xiaomi 14 and certain compatibility problems may concern on your whadaheck device. 

This project is powered by MediaPipe

This project has specs made by OpenSpec, use it as a vibe coding playground. 

This project welcomes pull requests if you think this project is garbage and want to make some changes to make it less garbage. I will try to review it.

## Features

- Works locally. No Internet connection required
- Swipe up / down by doing the specific gesture
- Hold your hand as a fist to return to Home
- Gestures are configurable
- Can work under certain apps to reduce battery cost and heat from camera
- You can try to play 2048 with it
